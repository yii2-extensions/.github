# Support

Use the following channels to get help with yii2-extensions packages.

- **Questions and general conversation**: [GitHub Discussions](https://github.com/orgs/yii2-extensions/discussions).
- **Bug reports and feature requests**: the issue tracker of the affected repository, using the provided issue forms.
- **Security vulnerabilities**: do not open a public issue; follow the [security policy](SECURITY.md).

Support is provided on a best-effort basis as maintainer availability permits.
