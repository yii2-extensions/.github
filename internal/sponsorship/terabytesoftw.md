# Support my open-source work in PHP

- [PHPStan for Yii2](https://github.com/yii2-extensions/phpstan).
- [RoadRunner integration for Yii2](https://github.com/yii2-extensions/road-runner).
- [FrankenPHP integration for Yii2](https://github.com/yii2-extensions/franken-php).
