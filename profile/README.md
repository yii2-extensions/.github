Integrations for Yii2 applications: static analysis, HTTP runtimes, and PSR-7 request handling.

Choose the integration for the part of your application you want to work on, from type analysis to the HTTP request
lifecycle. Read each repository's installation and compatibility notes before choosing a version. This organization is
independent of the official Yii project at [yiisoft](https://github.com/yiisoft).

## Documentation and contribution

Start with each repository's README, or explore the
[independent documentation portal](https://yii2-framework.github.io/docs/).

For questions and ideas, use the [organization Discussions](https://github.com/orgs/yii2-extensions/discussions).

Read the [contribution guide](https://github.com/yii2-extensions/.github/blob/main/CONTRIBUTING.md) before proposing a
change. For security concerns, follow the
[security policy](https://github.com/yii2-extensions/.github/blob/main/SECURITY.md).
