# yii2-extensions cover provenance

`yii2-extensions-cover-light.png` and `yii2-extensions-cover-dark.png` are 1280×360 opaque profile covers for light and dark themes. They are not avatar uploads or repository social previews. The earlier `yii2-extensions-cover.png` remains in the working tree as an unused draft.

## Yii emblem

Yii logo by the Yii project, [CC BY-ND 3.0](https://creativecommons.org/licenses/by-nd/3.0/); used unchanged. The [official Yii logo page](https://www.yiiframework.com/logo) identifies the license. The standalone source is the [official website repository's favicon at commit 64e3daf2687e842233c4a8089a142a110fb7f422](https://github.com/yiisoft-contrib/yiiframework.com/blob/64e3daf2687e842233c4a8089a142a110fb7f422/web/favico/favicon.svg), added in 2022. It is a historical official asset, not a claim about the website's current favicon.

The emblem's paths, proportions and colors are unchanged. It is rendered within a separate layout containing the organization name and background fields. The source SVG's SHA-256 is `4da383d97644df3e534ebb516b253f5c67c2af3c2e234173b30a93dff6865716`.

This organization is separate from the official Yii project. Use of the emblem does not assert upstream endorsement.

## Typography and image use

Typography uses unmodified Noto Sans, © The Noto Project Authors, under the [SIL Open Font License 1.1](https://openfontlicense.org/). No font binary is included here.

status and sponsor link. The image has no funding-allocation, compatibility,
